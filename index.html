Technology Stack

Core backend logic, state machine tracking, joint angle math, and data pipelines.

🎨 UI FRAMEWORK

Streamlit

Interactive frontend dashboard enabling real-time video component rendering.

Google's ultra-fast 33-point 3D landmark pose estimation pipeline.

NumPy

High-performance vector angle math and trigonometric posture checks.
